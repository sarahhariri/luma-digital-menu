# LUMA — Digital Cafe Menu

A modern and responsive digital menu designed for cafés.

LUMA allows customers to explore categories, search for products,
view product details, select sizes and extras, and see updated pricing
through a simple mobile-friendly interface.

## Features

- Responsive digital café menu
- Dynamic greeting based on the time
- Product search and category navigation
- Featured products section
- Product drawer with images and descriptions
- Dynamic sizes, extras, and price calculation
- Admin authentication
- Categories management
- Products management
- Extras management
- Cafe information management
- Responsive footer with contact and social links

## Built With

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- JavaScript
